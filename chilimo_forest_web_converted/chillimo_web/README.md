# Chilimo Forest Visitor Information System

A Python Tkinter desktop application providing visitor information about Chilimo Forest.

## Features

- Home page
- Forest history
- Wild animals information
- Birds information
- Plants information
- Attractions
- Location information
- English and Afaan Oromoo language support
- About page

## Technology

- Python
- Tkinter
- Git/GitHub


## Web version

The project now also includes a Flask web application. The original Tkinter desktop files are preserved, while `app.py` is the web entry point used for deployment.

Run locally with `python app.py`, or use Gunicorn in production with `gunicorn app:app`.
